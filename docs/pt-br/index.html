Começar

Carregue a extensão, conecte o Canvas e comece a conversar.

Instale a extensão

Firefox: baixe o .xpi da última versão e abra-o no Firefox para instalar com um clique. Chrome: baixe canvas-messenger-chrome.zip, descompacte-o e carregue a pasta em chrome://extensions (ative o Modo do desenvolvedor → Carregar sem compactação).

Conecte sua conta do Canvas

Abra a extensão e siga a configuração de token para vincular seu perfil do Canvas para que os colegas possam encontrá-lo.

Abra qualquer disciplina do Canvas

O painel de mensagens aparece sobre o Canvas. Inicie uma DM, crie um grupo ou entre no canal da turma.

Código aberto & auto-hospedável

Três repositórios compõem todo o sistema — todos públicos.

🧩

canvas-messenger

A extensão para Chrome/Firefox — a interface injetada no Canvas.

📡

cm-relay

API REST para registro, tokens de autenticação, convites e retransmissão de mensagens.

🔗

cm-signaling

Servidor de sinalização WebRTC que faz a intermediação de conexões ponto a ponto.

FAQ

A versão curta.

É gratuito?

Sim — gratuito e de código aberto sob a licença do repositório. Se isso te poupar a dor de cabeça de um chat em grupo, você pode buy me a coffee.

Funciona no Chrome e no Firefox?

Em ambos. Os scripts de compilação geram o manifesto correto para cada navegador.

Preciso do meu próprio servidor?

Não — para apenas usar o Canvas Messenger, instale a extensão e ela se conecta ao backend hospedado por padrão. Você só precisa do seu próprio servidor se quiser self-host toda a pilha: os servidores de retransmissão e sinalização são de código aberto e prontos para contêineres (imagens ghcr.io + Dockerfiles), para que você possa executá-los sozinho e apontar a extensão para seus próprios endpoints.

Isso é um produto oficial do Canvas?

Não. O Canvas Messenger é uma extensão independente criada pela comunidade. Não é afiliado ou endossado pela Instructure. Canvas é uma marca registrada da Instructure, Inc.

Onde estão meus dados?

As mensagens trafegam ponto a ponto via WebRTC sempre que possível; o relay lida com registro, convites e entrega. Auto-hospede o backend para manter tudo em uma infraestrutura que você controla.
