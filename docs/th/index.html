เริ่มต้นใช้งาน

ติดตั้งส่วนขยาย เชื่อมต่อ Canvas และเริ่มแชทได้เลย

ติดตั้งส่วนขยาย

Firefox: ดาวน์โหลดไฟล์ .xpi จาก รุ่นล่าสุด และเปิดใน Firefox เพื่อติดตั้งได้ด้วยคลิกเดียว Chrome: ดาวน์โหลด canvas-messenger-chrome.zip, แตกไฟล์ จากนั้นโหลดโฟลเดอร์ที่ chrome://extensions (เปิดใช้งานโหมดนักพัฒนาซอฟต์แวร์ → โหลดส่วนขยายที่ไม่ได้打包)

เชื่อมต่อบัญชี Canvas ของคุณ

เปิดส่วนขยายและทำตามขั้นตอนการตั้งค่าโทเค็นเพื่อเชื่อมโยงโปรไฟล์ Canvas ของคุณเพื่อให้เพื่อนร่วมชั้นหาคุณเจอ

คำถามที่พบบ่อย

สรุปสั้นๆ

ใช้งานฟรีไหม?

ใช่ — ฟรีและเป็นโอเพนซอร์สภายใต้ไลเซนส์ของคลังโค้ดนี้ หากมันช่วยให้คุณไม่ต้องปวดหัวกับการสร้างแชทกลุ่ม คุณสามารถ buy me a coffee.

ใช้งานบน Chrome และ Firefox ได้ไหม?

ได้ทั้งคู่ สคริปต์การสร้างจะผลิตไฟล์ manifest ที่ถูกต้องสำหรับแต่ละเบราว์เซอร์

ฉันต้องมีเซิร์ฟเวอร์ของตัวเองไหม?

ไม่จำเป็น — หากต้องการใช้งาน Canvas Messenger เฉยๆ ให้ติดตั้งส่วนขยายแล้วมันจะเชื่อมต่อกับแบ็กแอนด์ที่มีให้อยู่แล้วทันที คุณจะต้องมีเซิร์ฟเวอร์ของตัวเองก็ต่อเมื่อต้องการ self-host ระบบทั้งหมดด้วยตัวเอง: เซิร์ฟเวอร์ relay และ signaling เป็นโอเพนซอร์สและพร้อมใช้งานในรูปแบบคอนเทนเนอร์ (อิมเมจ ghcr.io + Dockerfiles) ดังนั้นคุณจึงสามารถรันมันเองและชี้ส่วนขยายไปยังปลายทางของคุณได้

นี่คือผลิตภัณฑ์อย่างเป็นทางการของ Canvas ใช่หรือไม่?

ไม่ใช่ Canvas Messenger เป็นส่วนขยายอิสระที่สร้างโดยชุมชน ไม่มีส่วนเกี่ยวข้องหรือได้รับการรับรองโดย Instructure ชื่อ Canvas เป็นเครื่องหมายการค้าของ Instructure, Inc.

ข้อมูลของฉันอยู่ที่ไหน?

ข้อความจะถูกส่งแบบ peer-to-peer ผ่าน WebRTC หากเป็นไปได้ ส่วน relay จะจัดการเรื่องการลงทะเบียน คำเชิญ และการจัดส่ง โฮสต์แบ็กแอนด์เองเพื่อให้ทุกอย่างอยู่บนโครงสร้างพื้นฐานที่คุณควบคุมได้
