Commencer

Chargez l'extension, connectez Canvas et commencez à discuter.

Installer l'extension

Firefox : téléchargez le .xpi depuis la dernière version et ouvrez-le dans Firefox pour l'installer en un clic. Chrome : téléchargez canvas-messenger-chrome.zip, décompressez-le, puis chargez le dossier sur chrome://extensions (activez le mode Développeur → Charger l'extension non empaquetée).

Connectez votre compte Canvas

Ouvrez l'extension et suivez la configuration des jetons pour lier votre profil Canvas afin que vos camarades puissent vous trouver.

Ouvrez n'importe quel cours Canvas

Le panneau de messagerie apparaît par-dessus Canvas. Démarrez un message direct, créez un groupe ou rejoignez le salon de cours.

Open source & auto-hébergeable

Trois dépôts constituent l'ensemble du système — tous publics.

🧩

canvas-messenger

L'extension Chrome/Firefox — l'interface utilisateur injectée dans Canvas.

📡

cm-relay

API REST pour l'enregistrement, les jetons d'authentification, les invitations et le relais des messages.

🔗

cm-signaling

Serveur de signalisation WebRTC qui établit les connexions pair à pair.

FAQ

La version courte.

Est-ce gratuit ?

Oui — gratuit et open source sous la licence du dépôt. Si cela vous évite les tracas d'un chat de groupe, vous pouvez Buy me a coffee.

Est-ce que ça fonctionne sur Chrome et Firefox ?

Les deux. Les scripts de compilation génèrent le manifeste correct pour chaque navigateur.

Ai-je besoin de mon propre serveur ?

Non — pour simplement utiliser Canvas Messenger, installez l'extension et elle se connecte au backend hébergé par défaut. Vous n'avez besoin de votre propre serveur que si vous souhaitez self-host toute la pile : les serveurs de relais et de signalisation sont open source et prêts pour les conteneurs (images ghcr.io + Dockerfiles), vous pouvez donc les exécuter vous-même et pointer l'extension vers vos propres points de terminaison.

Est-ce un produit Canvas officiel ?

Non. Canvas Messenger est une extension indépendante créée par la communauté. Elle n'est ni affiliée ni approuvée par Instructure. Canvas est une marque déposée d'Instructure, Inc.

Où sont mes données ?

Les messages transitent en pair à pair via WebRTC lorsque c'est possible ; le relais gère l'enregistrement, les invitations et la livraison. Auto-hébergez le backend pour garder tout sur une infrastructure que vous contrôlez.
